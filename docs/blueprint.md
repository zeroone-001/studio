# **App Name**: JNL Studio Booth

## Core Features:

- Smart Package Detector: Automatically validates payments of 50 or 100 PHP to initialize session logic and shot counts via Firestore background logic.
- High-Readability Kiosk UI: A portrait-locked, full-screen interface optimized for HONOR tablets using high-contrast typography for maximum accessibility.
- AI Portrait Enhancement: An AI reasoning tool that evaluates ambient lighting to automatically apply optimized filters and skin-tone preservation during capture.
- JNL STUDIO Identity: Dynamic generation and overlay of the JNL STUDIO brand logo on the welcome page, splash screen, and final print watermarks.
- USB-First Storage Sync: Background service prioritizing USB storage for photo persistence with automated JPEG compression and verification systems.
- Dynamic QR Soft-Copy: Instant generation of downloadable URLs and Facebook follow links with automated expiration logic and metadata triggers.
- Kiosk Recovery Monitor: Real-time tracking of hardware health for printers and bill validators with automatic session recovery states.

## Style Guidelines:

- Primary Background: Pure Black (#000000) for a premium, high-contrast aesthetic.
- Text and Primary Details: Stark White (#FFFFFF) to ensure maximum readability and accessibility against dark backgrounds.
- Brand Accents: Neon Pink (#FF3399) for interactive elements, buttons, and high-visibility touch targets.
- Headlines and body text use 'Inter' (sans-serif) with bold weights to guarantee legibility on high-resolution kiosk tablets.
- Minimalist camera-inspired line icons styled with neon glowing outlines to reinforce the premium studio brand.
- Responsive portrait-only grid for HONOR tablets using SafeArea and AspectRatio to prevent UI stretching or overflow.
- Subtle neon pulse effects during countdowns and smooth fade-in transitions for frame selection previews.
